# 🛍️ ShopNest

**ShopNest** is a stylish and responsive eCommerce web application built using **React.js** and **Tailwind CSS**. It offers a smooth and interactive shopping experience with modern UI elements and features like Dark/Light mode, a carousel slider, and a mobile-friendly layout. Ideal for showcasing products and engaging users with a seamless frontend shopping interface.

---

## ✨ Key Features

- 🌗 **Dark & Light Mode Toggle** – Seamlessly switch between themes for user comfort.  
- 🖼️ **Hero Section with CTA** – Attractive landing section with product highlights.  
- 🛍️ **Product Listings** – Dynamic product cards with hover animations and order buttons.  
- 🌟 **Top-Rated Products** – Highlight your best products with styled cards and star ratings.  
- 💬 **Testimonial Carousel** – Responsive customer reviews powered by React Slick.  
- 📩 **Subscribe Section** – Capture user emails for marketing via a clean input form.  
- 🖥️ **Fully Responsive Design** – Optimized for all devices (mobile, tablet, desktop).  
- 🎉 **Popup Modal** – Order now modal triggered by multiple sections.  
- 🎯 **AOS Animations** – Smooth scroll animations throughout the page.  

---

## 🛠️ Technologies Used

- **React.js** – Frontend library  
- **Tailwind CSS** – Utility-first CSS framework  
- **AOS (Animate on Scroll)** – Scroll-based animations  
- **React Icons** – Icon library  
- **React Slick** – Carousel/slider component
